# Cheapest-Convenience
Recommend the cheapest convenience store to buy

## Period
22.11.01 ~ 22.11.30

## Background
There are three convenience stores (Seven Eleven, GS25, and CU) around Korea University Sejong Campus. All three convenience stores may have different prices or discount rates for a single product. 

Considering all of these situations, we wondered which convenience store was the cheapest to buy when we purchased a certain number of items.

In other words, for rational consumption of students, we intend to develop a web that informs them using Django and MySQL.

## Expected Outcomes
Korea University students can identify the cheapest convenience store when they purchase a certain number of items they want. This will allow them to purchase the items they need while saving money.

In addition, it is possible to reduce the hassle of visiting convenience stores one by one and comparing prices or checking discount information.

Using a web application, we can quickly compare information from various convenience stores and make an optimal selection.
